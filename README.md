# pesaclarity/.github

Organisation-wide defaults for every Pesa Clarity repository: the public profile, contributing guide, code of conduct, security policy, and issue and pull request templates. GitHub applies these to any repo in the organisation that does not have its own.

| File | Purpose |
| --- | --- |
| [profile/README.md](profile/README.md) | Organisation profile shown at github.com/pesaclarity |
| [CONTRIBUTING.md](CONTRIBUTING.md) | How to contribute to any repo |
| [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) | Contributor Covenant 2.1 |
| [SECURITY.md](SECURITY.md) | How to report a vulnerability privately |
| [ISSUE_TEMPLATE/](ISSUE_TEMPLATE/) | Bug, feature and new-institution forms |
| [pull_request_template.md](pull_request_template.md) | Default pull request checklist |

Spec and brand live in [pesaclarity/docs](https://github.com/pesaclarity/docs).
